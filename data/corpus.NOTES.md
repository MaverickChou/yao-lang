# 辞库说明（请先读这一页）

`data/corpus.txt` 是**手改的源头**，`data/corpus.json` 是生成物。
直接改 JSON 会在下次 `tools/build_corpus.py` 时被覆盖。

## 为什么标 draft

这 450 条是凭记忆转录的，结构由 `build_corpus.py` 全部机器校验过
（64 卦齐全、每卦六爻、无空条目、卦内爻辞不重复），
但**逐字比对纸本这一步没有做**。对照任何一部纸本，都可能发现出入。

开源项目不该在这一点上含糊：能跑，不等于考据准确。

## 已知的不确定点

1. **句读**。不同标点本断句不同。例如乾九三：
   - 本库：「君子终日乾乾，夕惕若，厉无咎」
   - 亦有作：「君子终日乾乾，夕惕若厉，无咎」

   两种读法都有传承（「若」作语助 / 连读）。本库取前一种，**全库句读需统一复核**。
2. **异体与通假**。如 遯/遁、咸、说/脱、有/又、无/無。本库用简体通行字形，
   但《易》本文中若干处用字有讲究（如「无」不作「無」），校对时要逐字看。
3. **个别字**。如「夕惕若」的「若」、「窒惕」的「窒」，不同版本可能有异文。

## 校对流程

```
1. 看 yao corpus --unverified，挑一条
2. 打开 data/corpus.txt，对照纸本核对那一行
3. 改对了，就在 data/corpus.verified.txt 里加一行键（如 乾.1）
4. python tools/build_corpus.py     # 重新生成 corpus.json
5. node --test
```

键的格式：

| 键 | 含义 |
|---|---|
| `乾.c` | 卦辞 |
| `乾.1` … `乾.6` | 第 1..6 爻爻辞（自初爻起） |
| `乾.u` | 用九 / 用六（只有乾坤有） |

一次核完一卦（卦辞 + 六爻）就加七行。

`corpus.json` 里的 `status` 由已校对比例自动决定：全部核完会变成 `verified`。
`yao corpus --strict` 在存在未校对条目时退出码为 1，可用于「发布级」构建。

**这个清单目前是空的**，也就是 450 条一条都没核过。清单是给人签字的，
不是自动生成的——不要为了让 CI 变绿而往里填。
