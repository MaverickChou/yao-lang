# 卦境 · 六十四卦地牢

一个小游戏，同时也是爻的旗舰示例。它只用了语言的全部能力：64 个态、4 条规则。

```bash
yao run gua_jing.yao
```

```
1-6 变第 n 爻   c 错卦   z 综卦   h 互卦   q 退出
```

## 规则

你在 64 个房间之间行走，每个房间是一个卦。起点是 **未济**（未完成），
终点是 **既济**（已完成）——六十四卦里唯一全当位的那个。

| 输入 | 事件 | 效果 |
|---|---|---|
| `1`–`6` | 行(n) | 翻转第 n 爻，走到相邻房间 |
| `c` | 错卦 | 六爻全变，走到对径点 |
| `z` | 综卦 | 爻序倒转，进入镜像世界 |
| `h` | 互卦 | 走进卦的内部结构 |

## 状态就是 12 位的 `变`

```
本 = 你现在在哪一间
动 = 你是从哪条爻走进来的
之 = 本 ^ 动 = 上一间房
```

所以「来路」不需要额外的变量——它就在状态里。用 `错卦` 时 `动 = 111111`，
`之` 恰好指回你来的房间，因为错卦是六爻同时翻转。

## 最短与最长

`yao check gua_jing.yao` 会把 4096 个可能状态全部走一遍，实测结果：

```
可达态      512 / 4096      （64 房间 × 8 种动爻）
态可达      64 / 64         全部房间都走得到
死态        0               没有走不出去的房间
未定义转移  0 / 256         四个动作在每一间房都有定义
强连通      是（1 个分量）
图直径      4 步
```

- **最短**：1 步。按 `c` 即可，因为 未济 ䷿ 与 既济 ䷾ 互为错卦。
- **离起点最远**：3 步。乾 与 坤 都是 3 步。
  一条到 乾 的路是 `行:1 → 行:3 → 行:5`（未济 → 睽 → 大有 → 乾）。
- **全图直径**：4 步。
