# 爻阵

一个能用手指头玩的解谜游戏，也是爻目前唯一"完成品"级的程序。

```bash
yao game
```

## 规则

按第 n 爻，**该爻与它相邻的爻一起翻转**——这是《易》里"动一爻而牵动其比"的直译。
所以你不能只改正想改的那一位：按下它，旁边两位也跟着变。

| 按 | 翻转 |
|---|---|
| 1 | 初、二 |
| 2 | 初、二、三 |
| 3 | 二、三、四 |
| 4 | 三、四、五 |
| 5 | 四、五、上 |
| 6 | 五、上 |

## 玩法

六关，每关给你一个目标卦（泰、谦、复、咸、大有、既济），把当前卦走到目标即可。

- 每关都显示**最优步数**，由宿主在 64 节点图上现算 BFS 得出，不是写死的。
- 步数上限 = 最优 + 2，超了本关重来。
- 走出最优解会有提示。

## 为什么这个机制成立

移动是 GF(2) 上的线性变换，"按两次等于没按"，所以 64 个卦在六种按法下
构成一个连通图——**任何目标都可达**，这保证了六关全部可解。
`tests/game.test.js` 对这一点做了直接断言：从任一卦出发，64 卦全部可达。

## 文件

| 文件 | 说明 |
|---|---|
| `yao_zhen.yao` | 状态机，64 态 1 规则，由 `tools/gen_yao_zhen.py` 生成 |
| 游戏壳 | `src/game.js`（关卡、BFS 最优步数）+ `bin/yao.js` 的 `cmdGame` |

游戏壳**不重写规则**：最优步数是用真实的机器语义一步步走出来的。
规则改了，最优步数自动跟着改。
